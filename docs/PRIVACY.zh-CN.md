# 隐私与网络边界

[简体中文](PRIVACY.zh-CN.md) | [English](PRIVACY.md)

FinancialBeancount 是本地优先账本。除非用户主动复制或分享导出文件，否则账单文件、标准化交易、原始行、审核历史、统计、备份和导出内容均留在用户设备上。

## 网络行为

- 桌面账本服务随机绑定 `127.0.0.1` 端口。除非操作者明确配置 API 令牌，否则拒绝绑定非回环地址。
- 应用不包含遥测、分析、崩溃上报或广告客户端。
- 应用包中唯一的出站客户端是更新器。只有用户点击“检查更新”后才会请求配置的 HTTPS Release 端点；请求包含应用版本和普通 HTTP 元数据，不读取或传输账本数据库、账单文件、交易字段、账户标识或备份。
- 将 `FINANCIAL_BEANCOUNT_UPDATE_API` 设为禁用值后，应用保持完全离线；自定义更新端点必须使用 HTTPS。

## 浏览器与缓存

- API 响应使用 `Cache-Control: no-store`，且不会进入 Service Worker 缓存。
- Service Worker 只缓存同源的内置应用外壳静态资源。
- 内容安全策略只允许同源脚本、样式和 API 连接；禁用 frame 和插件对象，并抑制来源信息。
- 浏览器持久存储中只保存本地审核者标签。API 地址和可选令牌使用会话存储，会随浏览器会话结束而消失；交易数据不会写入浏览器存储。

## 本地诊断

桌面启动和更新诊断保存在用户数据目录或更新暂存目录旁，不会自动上传。旧版 CLI 的详细输出可能包含本地文件名或简短交易描述，分享错误报告前应先检查控制台内容。

## Release 隐私门禁

若更新器之外出现新的出站 HTTP 客户端、内置 Web 资源引用外部资源、API 响应变得可缓存，或 Service Worker 开始缓存 `/api/` 响应，自动化测试必须失败。任何有意调整均须进行明确的隐私审查，并同步更新本中英文文档。
